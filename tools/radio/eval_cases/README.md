# RADIO eval cases

Twelve golden cases, one per row of `docs/RADIO_SPEC.md` section 10. Each is a **PACK v1**
fixture drawn from a verdict the ledger already paid for, plus deterministic assertions
the debrief for that pack must satisfy. The engine is `tools/radio/eval.py`; the
regression tests are `tools/radio/test_eval.py`.

    python3 tools/radio/eval.py --list
    python3 tools/radio/eval.py --selftest                 # 12/12 + 12/12
    python3 tools/radio/eval.py --debriefs <DIR>           # scores <case_id>.json in DIR
    python3 tools/radio/eval.py --refresh-packs            # needs state/etk_telemetry/

Scoring (section 10.3): the rules-only baseline must be **12/12** -- it is the pipeline's
contract -- and so must any model, with the operator's blind read (more useful / same /
worse than rules-only) deciding on top. The `rubric` line in each case is that human
column; nothing in this directory grades it.

## What a case is

| key | what it holds |
|---|---|
| `id` | one of the twelve spec 10 ids; the file is `<id>.json` |
| `from` | one sentence of provenance: the ledger verdict and its date |
| `source` | `{kind: ledger\|synthetic\|service, epoch, generated_by}` -- `epoch` and `generated_by` are set only for `ledger` cases, where `epoch` equals `pack.epoch` |
| `pack` | the PACK v1 object the analyst sees; nothing else is in front of it |
| `expect` | the assertions (below). Each may carry a `why` for the human reader |
| `rubric` | one line for the blind read -- what a good answer says |
| `exemplar` | a DEBRIEF v1 that passes **every** assertion |
| `counter` | the realistic WRONG answer that must fail **at least one** |
| `model_output` | `hallucinated_key` only: the raw model JSON, pre-guards, for the service's fake-Ollama test |

The exemplar/counter discipline is copied from `tools/radio/exam.py`: `--selftest`
grades both, so an assertion that would pass a wrong debrief or fail a right one is
caught before a model ever sees it. Tests discriminate or they do not count.

## Where the packs come from

Eight cases are real ledger rows, regenerated by `bin/radio_pack.py <epoch> --stdout`
against the host mirror. Four are synthetic: `attract_row` (no attract marker has ever
existed in the ledger -- attract was how a run was driven, never a `tune_tag`),
`res_lowering_kpi` and `falsified_tempt` (the temptation lives in the operator's note),
and `hallucinated_key` (the pack is untouched evidence; the case lives in
`model_output`). A synthetic pack starts from a real pack and changes only what the case
needs; `pack_notes` says so, in the pack, starting with `synthetic:`.

Packs are stored under the DECIDED PACK v1 field names, which a pack generated today
does not all carry yet -- `eval.normalize_pack()` renames on the way in
(`history.recent_changes` -> `history.changes_since_last_debrief`,
`timeline.gpu_temp_c` -> `timeline.temp_c`) and adds the agreed keys as `null` when the
packer has no value for them (`rig.os`, `rig.kit`, `timeline.perfect_windows`,
`run_sheet`). It renames; it never invents a value.

## Refreshing

    python3 tools/radio/eval.py --refresh-packs

Re-runs the packer for every `ledger` case, normalizes, and rewrites the `pack` and
`source.generated_by` in place. Synthetic packs are never touched, and a missing
`state/etk_telemetry/` is reported and skipped, not an error -- the eval has to run on
the node, where there is no telemetry at all. The refresh is idempotent: run it twice
and nothing changes. After refreshing, re-run `--selftest`; if the ledger moved under a
case, an exemplar will say so.

## The assertion ops

Every assertion is `{"op": ..., ...}`. Unknown ops and malformed ones fail loudly.

| op | keys | asserts |
|---|---|---|
| `tags_include` | `tags[]` | the debrief carries these tags; the detail line says which of them the pack itself computes |
| `tags_exclude` | `tags[]` | none of these tags is claimed |
| `finding_kinds_exclude` | `kinds[]` | no finding of these kinds |
| `finding_kind_present` | `kind` | at least one finding of this kind |
| `recommendation_kinds_subset` | `kinds[]` | every recommendation's kind is in this set |
| `recommendation_kind_present` | `kind` | at least one recommendation of this kind |
| `recommendation_kind_first` | `kind` | `recommendations[0].kind` -- order matters, e.g. investigate before any tune |
| `config_key_absent` | `yaml_key` | no `config_changes` entry names this key |
| `config_no_decrease` | `yaml_key`, `below` (optional) | this key is never set below `below`; without it the floor is read from the pack (`config.values` / `config.yaml`, or `session.res_scale` for Resolution Scale) |
| `text_forbids` | `regex`, `fields[]` (optional) | no field matches |
| `text_requires` | `regex`, `fields[]` (optional) | some field matches |
| `evidence_source_present` | `source` | some finding's evidence carries this source (`aud`, `ledger`, `dmesg`, `dyno`, `blackbox`, `manual`, `pack`) |
| `comparison_needs_n` | -- | every finding whose text COMPARES arms carries evidence with two N >= 3 |
| `guards_dropped_mentions` | `regex` | `guards.dropped` names the drop and its reason |
| `guards_passed` | `value` (default true) | `guards.passed` |
| `schema_valid` | -- | DEBRIEF v1; defers to `tools/radio/schemas.py` when present, else a built-in shape check. A foreign top-level key is invalid either way |

`fields` for the text ops: `radio`, `headline`, `findings.text`,
`recommendations.text`, or `all` (the default is all four).

`comparison_needs_n` decides "this finding compares arms" from the text (`vs`,
`versus`, `better than`, `beats`, `cuts the ... by`, `Nx better`, ...) and counts an
evidence entry as citing an arm's N when its `field` is `n` or ends in `.n` / `_n`
(`sddepth.n`, `arm_n`). Two such values, both >= 3, or the assertion fails.

## Computed tags

`eval.compute_tags(pack)` implements spec 3.2's node-computed tags so an assertion can
say what the pack itself supports: `bake` (`shaders_harvested > 5`), `aborted`,
`attract` (the operator's mark), `low_n` (no dyno arm at N >= 3 matches this session's
clock + power rung + dial), `keepalive_absent` (a fault status with `rescues` **equal
to** 0 -- a blank cell is a pre-column-era row, not a keepalive that failed),
`panic_silent` (PANIC with no fault, oops or trace in the kept kmsg tail).
`stack_change` is **not** computed: today's pack carries no per-history-row stack to
compare against, so it is left to the node and asserted by no case.
